# 🎭 Cultura no Bairro

## 📌 Sobre o projeto

O **Cultura no Bairro** é um sistema web desenvolvido com o objetivo de divulgar atividades culturais e facilitar o acesso da comunidade a oficinas e eventos culturais.

A plataforma busca aproximar a população das oportunidades culturais disponíveis, permitindo que os usuários conheçam as oficinas e realizem inscrições de forma online.

## 🎯 Objetivo

Promover o acesso à cultura por meio de uma plataforma digital que divulga atividades culturais e facilita a participação da comunidade em oficinas e eventos.

## ✨ Funcionalidades

- 📅 Visualização da agenda cultural.
- 🎨 Divulgação de oficinas e atividades culturais.
- 📝 Formulário de inscrição nas oficinas.
- 👤 Cadastro de participantes com nome, e-mail e telefone.
- 💾 Armazenamento das inscrições em banco de dados.
- ✅ Confirmação de inscrição após o envio do formulário.
